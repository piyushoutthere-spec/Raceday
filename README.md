## RaceDay | F1 Companion

RaceDay is a Formula 1 companion website designed to help fans keep track of upcoming races and important race information in one simple interface.

The project provides a live countdown to the next race, an interactive race calendar, and detailed information for selected Grand Prix events. It was built as a lightweight frontend project using HTML, CSS, and JavaScript, with a focus on responsive design and interactive functionality
## Technologies Used
- HTML5 — page structure and content
- CSS3 — layout, responsive design, styling, and modal interface
- JavaScript — countdown timer and interactive race information
- GitHub Pages — hosting the finished website

## Known Limitations
- Race information is currently entered directly into the JavaScript rather than retrieved from a live Formula 1 data API.
- The calendar currently contains a limited selection of races.
- There is no backend, user account system, or database.
- Race dates and information must be updated manually when the calendar changes.
