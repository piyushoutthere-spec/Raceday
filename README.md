## Features
1 live countdown to next race
2.calendar
3.Dark F1 inspired Interface
4.Simple interactive information
## Built with
HTML
CSS
JavaScript
## Project Purpose
I built this as a beginner friendly web development project to practise and be good with HTML,CSS and Javascript.
